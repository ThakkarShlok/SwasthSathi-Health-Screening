# 🩺 SwasthSathi

**Offline-Capable Health Screening System for Diabetes & Hypertension**

SwasthSathi is a frontend-based health screening web application designed to help users identify early risk of **Diabetes and High Blood Pressure together**.  
The project is focused on **rural and low-connectivity environments**, where access to doctors and internet is limited.

This project was built as part of **ImpactThon 2025–26**.

---

## 🎯 Problem Statement

Diabetes and Hypertension often occur together and significantly increase the risk of heart disease, stroke, and kidney failure.  
In rural India, people usually get screened late, often for only one condition, and struggle to understand medical reports written in English.

SwasthSathi aims to:
- Perform **early co-risk screening** (not diagnosis)
- Work **offline** using a smartphone
- Provide **simple explanations and lifestyle guidance**
- Help users take timely medical action

---

## ✨ Features

- Offline-first web application (no internet required)
- Screens **Diabetes & Hypertension together**
- Simple and user-friendly form-based screening
- Local data storage using browser storage
- Clean and responsive UI using Bootstrap
- Designed for patients and ASHA / health workers

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Bootstrap 5  

---

## 🚀 How to Run the Project

1. Download or clone the repository  
2. Open the project folder in **VS Code**
3. Open `swasthsathi.html` in your browser  
4. Click **“Start Screening”**
5. Fill the form and submit  
6. Data is saved locally in the browser

> No installation required.
